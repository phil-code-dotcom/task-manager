QUESTION 

Assignment: Student Task Manager

Create a simple Student Task Manager using HTML, CSS, and JavaScript DOM Manipulation.

The page should contain an input field where a student can enter a task and a button to add the task. When the button is clicked, use JavaScript to create and display the task on the page. Each task should have a Delete button that removes the task from the page when clicked.

Your program should also display the total number of tasks currently on the page and update the number whenever a task is added or deleted.

Requirements

* Use JavaScript DOM Manipulation to create and modify elements.
* Use `addEventListener()` to handle button clicks.
* Allow the user to add multiple tasks.
* Each task must have its own Delete button.
* The Delete button must remove only the task it belongs to.
* Display the current number of tasks.
* Do not use `alert()` for displaying tasks.
* Do not hard-code the tasks into the HTML.
* Prevent the user from adding an empty task.

Bonus Challenge

Add a Clear All button that removes all tasks at once and resets the task counter to `0`.
